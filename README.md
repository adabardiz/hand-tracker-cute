A computer vision project that uses OpenCV & Mediapipe. It tracks your hands in real time, taking your four fingers as points in a 'rectangle'. 
It then applies a pink-ish filter to the area between the four points of the rectangle (your fingers)

Features:
- Doesn't work if two hands aren't in the frame
- Detects two hands simultaneously in real-time
- Uses OpenCV's COLORMAP_SPRING for a high contrast magenta & yellow filter.
